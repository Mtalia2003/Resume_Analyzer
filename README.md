# Resume_Analyzer
AI-Driven Resume & ATS Analysis Tool A Flask-based web application that utilizes Large Language Models (LLMs) to automate resume screening and interview preparation.

Core Logic: Integrates Google Gemini Pro for intelligent resume-to-JD matching and skills extraction.
Analytics: Features a custom scoring algorithm combining keyword frequency and AI-derived semantic relevance.
Accessibility & UX: Implemented gTTS (Google Text-to-Speech) for audio analysis summaries and ReportLab for dynamic PDF report generation.
Prep Module: Dynamically generates behavioral and technical interview questions based on identified skill gaps.
Stack: Python, Flask, Gemini AI, gTTS, PDF processing, HTML5/CSS3.
